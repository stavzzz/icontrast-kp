02 · ШЕСТЬ АГЕНТОВ

Каждый агент — под конкретную задачу и конкретного человека

Это те самые шесть задач из вашего ТЗ. Для каждой — что делаем, как это работает и какой результат получает постановщик. Статус ПРОДАКШН — рабочий инструмент к концу проекта. Там, где есть внешние ограничения (например, регистрация бота в Max), честно пишем их прямо в карточке.

📝 Агент «Пост-мит» — задачи из созвонов за 10–15 минут Задача Никиты Попова
ПРОДАКШН
Сейчас: запись → ручная транскрипция → вручную в Claude с промтом → вручную в таблицу. Делаем полный автомат: закинули запись созвона — агент сам транскрибирует, извлекает задачи и раскладывает их в рабочую среду.
Запись созвона → транскрипция → ИИ-разбор → Google-таблица:
задача · ответственный · приоритет · комментарий — через 10–15 минут после звонка
Результат: ни одна договорённость с клиентом не теряется. Никита перестаёт тратить вечер на разбор записей — задачи появляются в инфополе сами.
📈 Агент «SEO-переводчик» — отчёты с вау-эффектом из Топвизора Задача Георгия
ПРОДАКШН
Проблема знакомая: позиции растут, а клиент видит таблицу сырых цифр и читает её как стагнацию. Агент берёт выгрузку из Топвизора и систем сбора позиций и превращает её в отчёт на языке бизнеса: что выросло, почему это важно, какие работы к этому привели.
Выгрузка Топвизора → анализ динамики → подсветка роста, графики,
пояснение ключевых запросов → готовый отчёт «глазами клиента»
Результат: клиент видит ценность работы SEO-отдела, а не «опять какие-то проценты». Меньше вопросов «а что вы вообще делали в этом месяце».
🖥 Дашборд Яндекс.Директ + Метрика с гостевым доступом Задача Георгия
ПРОДАКШН
Автовыгрузка из Яндекс.Директа и Яндекс.Метрики по API в единый дашборд. Директолог видит аналитику в реальном времени и экономит 15–60 минут на каждом отчёте. Клиенту — гостевая ссылка с персональным видом: только его метрики (заявки, конверсия, CPL), без внутренней кухни.
API Директа + Метрики → автообновление дашборда →
вид директолога (всё) · гостевая ссылка клиента (заявки · конверсия · CPL)
Результат: еженедельные и ежемесячные отчёты собираются сами. Клиент чувствует прозрачность — это удерживает его в агентстве.
📊 Агент «Фирменный отчёт» — презентации из статистики Задача Алины
ПРОДАКШН
Сейчас красивые отчёты собираются вручную через Perplexity и Claude. Делаем то, что вы и просили: «закинул данные → получил красивый отчёт». Единый фирменный шаблон в стиле «Контраста» — агент сам раскладывает статистику по слайдам, считает выводы и оформляет.
Загрузка статистики → разбор данных → фирменный шаблон «Контраста» →
готовая презентация-отчёт без ручной настройки
Результат: часы ручной вёрстки превращаются в минуты. Все отчёты агентства выглядят одинаково дорого — в ваших цветах.
🔍 Агент «Радар» — еженедельные сводки по конкурентам и трендам Задача Алины
ПРОДАКШН
Каждую неделю агент сам обходит авторитетные Telegram-каналы и новостные ресурсы по маркетингу, собирает активности конкурентов и тренды. Главное требование вашего ТЗ соблюдаем жёстко: каждый факт — со ссылкой на источник. Нет ссылки — факт не попадает в сводку. Никаких галлюцинаций.
Расписание (раз в неделю) → мониторинг TG-каналов и СМИ →
структурированная сводка: тренд · конкурент · ссылка на источник
Результат: единое место вместо ручных запросов в Perplexity. Сводка приходит сама — Алина читает, а не собирает.
🕐 Агент «Хронограф» — фото рабочего дня Задача Алины
ПРОДАКШН
Ежедневная сводка: на что ушло время, с разбивкой по задачам и ролям (руководитель проектов vs куратор проджектов). Покрываем оба мессенджера: Telegram — через выгрузку, Max — через официальный Bot API (dev.max.ru): бот добавляется в рабочие чаты, читает сообщения в реальном времени и умеет выбирать историю за период.
Бот в рабочих чатах Max (message_created + история за период) + Telegram-чаты + задачи →
ежедневная сводка: время · задача · роль (руководитель проектов / куратор проджектов)
Честные оговорки по Max: бот регистрируется только от верифицированного юрлица РФ (ИП не подходит — оформим через наше юрлицо или ваше партнёрское) и проходит модерацию. Историю чатов до момента добавления бота документация не гарантирует — проверим на пилоте в первую неделю. Telegram-часть работает в любом случае.
Результат: ежедневное фото рабочего дня по чатам Max, Telegram и задачам — то самое, чего не хватало после переезда чатов в Max.
